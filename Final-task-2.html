PROJECT DESCRIPTION

Finals task 2. Navigating Power BI

This project focuses on using Power BI to perform data preparation, data modeling, analysis, and visualization using flight and airport datasets. The activity begins with importing CSV files and cleaning the data by correcting labels, handling missing values, removing unnecessary columns, and organizing the dataset into fact and dimension tables.

The project also introduces the process of building a Star Schema data model to improve data organization and analysis. Using DAX formulas, several calculated columns and measures are created to analyze flight performance, including delayed, canceled, diverted, and on-time flights.

In the final stage, interactive visualizations are developed to present insights from the dataset. These dashboards help analyze airline operations, flight statuses, and airport-related information through charts, graphs, and summary metrics. The activity strengthens practical skills in Power BI, data modeling, DAX calculations, and business intelligence reporting.
